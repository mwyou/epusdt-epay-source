# Epusdt EPay source packages

This public repository publishes versioned source bundles corresponding to the public Docker images at `cotelforce/epusdt-epay`.

Each versioned release contains a source archive for the exact code revision used to build that image. The archive includes the license and attribution files and does not include the private development repository's Git history. See the archive in each release, not this repository's README-only history, for the application source.

- Latest source package: https://github.com/mwyou/epusdt-epay-source/releases/latest
- Private development repository: https://github.com/mwyou/epusdt-epay
